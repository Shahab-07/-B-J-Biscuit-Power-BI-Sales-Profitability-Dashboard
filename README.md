# 🍪 B&J Biscuit – Power BI Sales Dashboard

An interactive **Power BI dashboard** analyzing sales, revenue, profitability, and customer insights for B&J Biscuit.  
This project demonstrates strong data modeling, KPI design, and business intelligence storytelling.

---

## 📊 Key KPIs

- **Quantity Sold:** 3,050,309  
- **Total Revenue:** $6,156,7883  
- **Total COGS:** $3,478,3050  
- **Profit Margin:** 43.5%  
- **Best Selling Biscuit:** Shortbread  
- **Most Profitable Location:** San Antonio  
- **Most Profitable Customer:** Robert Hernandez  
- **Top Salesperson:** Travis Doyle  
- **Most Profitable Age Group:** 55+  

---

## 📈 Dashboard Highlights

- Revenue distribution by price category  
- Quarterly, monthly, and weekly revenue contribution  
- Revenue by location  
- Top 5 customers by revenue  
- Revenue by gender and age group  
- Payment method analysis (Cash, Credit, Debit, Mobile)  
- Interactive filters (Location, Age Group, Payment Method)  
- Toggle between Absolute Value, Percentage, and MoM change  

---

## 🛠 Tools Used

- Power BI Desktop  
- DAX  
- Data Modeling  
- Interactive Visualizations
